# Домашка 3

- `task_1` считает среднюю температуру, минимум, максимум и число морозных дней.
  Введите число дней, а затем температуру за каждый день.
- `task_2` работает как копилка. Команды:
  1. `deposit k` положить деньги,
  2. `withdraw k` снять деньги,
  3. `balance` посмотреть сумму,
  4. `reset` обнулить,
  5. `inc` добавить рубль,
  6. `stop` выйти.

  Вместо `k` укажите сумму в рублях.
- `task_3` выводит табло из 5 строк и 10 столбцов.
  1. `put x y c` ставит символ,
  2. `text x y слово` пишет слово,
  3. `print` показывает табло,
  4. `clear` очищает его,
  5. `quit` завершает работу.

  Здесь `x` это столбец, `y` это строка.
- `task_4` хранит сетку чисел. Сначала введите количество слоёв, строк и
  столбцов, затем числа по строкам каждого слоя. Команды:
  1. `sum` показывает суммы по слоям,
  2. `average` показывает средние,
  3. `cell слой строка столбец` показывает одну ячейку.

  Нумерация начинается с нуля. Для выхода введите `stop`.

Для сборки нужны компилятор C++17, CMake и Ninja.
Откройте терминал в корне репозитория и выполните команды.

Linux или macOS:

```sh
cmake -S homework_03 -B /tmp/cpp_mipt_homework03_build -G Ninja
cmake --build /tmp/cpp_mipt_homework03_build
/tmp/cpp_mipt_homework03_build/task_1
```

Windows, PowerShell. Команда `g++` должна быть доступна в терминале:

```powershell
cmake -S homework_03 -B "$env:TEMP\cpp_mipt_homework03_build" -G Ninja -DCMAKE_CXX_COMPILER=g++
cmake --build "$env:TEMP\cpp_mipt_homework03_build"
& "$env:TEMP\cpp_mipt_homework03_build\task_1.exe"
```

Эти команды собирают все задачи и запускают дневник. Для запуска другой задачи замените `task_1` в последней команде на `task_2`, `task_3` или `task_4`. После запуска введите данные в терминале.
